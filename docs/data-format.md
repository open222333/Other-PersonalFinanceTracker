# 匯入匯出格式

系統提供兩種格式：

| 格式 | 用途 | 匯出 | 匯入 |
|---|---|---|---|
| **收支 CSV** | 銀行 / 信用卡對帳單、Excel 整理的收支；人可讀可編輯 | 「匯入匯出」頁或收支頁（依目前篩選） | 「匯入匯出」頁，先預覽再寫入，**新增**到現有資料 |
| **完整備份 JSON** | 備份、搬移到另一台機器 | 「匯入匯出」頁 | 「匯入匯出」頁的「還原備份」，**取代**目前所有資料 |

欄位規格的程式來源是 `src/features/data/format.ts`，頁面上的說明與範本都由它產生；修改格式時兩邊一起改。

---

## 1. 收支 CSV

範例檔：[`samples/transactions-sample.csv`](./samples/transactions-sample.csv)（也可在頁面上「下載範本」）

```csv
日期,類型,金額,帳戶,分類,轉入帳戶,轉入金額,對象,備註,標籤
2026-11-19,支出,120,現金錢包,餐飲/午餐,,,便當店,,
2026-11-05,收入,68000,台新 薪轉戶,薪資,,,公司,11 月薪資,
2026-11-15,轉帳,21373,台新 薪轉戶,,國泰 CUBE 卡,,,繳信用卡費,
2026-11-20,轉帳,32150,台新 薪轉戶,,台新 美元帳戶,1000,,換匯,
2026/11/18,,-390,國泰 CUBE 卡,娛樂/訂閱,,,Netflix,類型留空，依負數判斷為支出,訂閱、影音
```

### 檔案

- **編碼**：匯出為 UTF-8（含 BOM，Excel 可直接開啟）；匯入接受 UTF-8 或 Big5（自動判斷）
- **分隔符號**：匯入時自動判斷逗號、Tab、分號；匯出用逗號
- **第一列為標題**；欄位順序不拘；認不得的欄位會略過並提示
- 含逗號、雙引號或換行的欄位需以雙引號包住，內部的 `"` 寫成 `""`（Excel 會自動處理）
- 上限：10,000 筆、5 MB

### 欄位

標題比對不分大小寫、忽略前後空白；「也接受」欄的標題可直接對應銀行匯出檔的常見欄名。

| 欄位 | 也接受 | 必填 | 說明 |
|---|---|---|---|
| `日期` | date、交易日期、交易日、消費日期、記帳日期 | ✓ | `2026-11-19`、`2026/11/19`、`2026/1/5`、`2026.11.19`、`20261119`，或民國年 `115/11/19` |
| `類型` | type、收支、收支類型 | | `支出`、`收入`、`轉帳`（或 `expense`、`income`、`transfer`）。**留空時依金額正負判斷**：負數為支出、正數為收入 |
| `金額` | amount、交易金額、金額(元) | ✓ | 最多兩位小數；可含千分位 `1,234`、`$`、`NT$`、`US$`、結尾的「元」；`(120)` 視為 -120。有填類型時取絕對值；不可為 0 |
| `帳戶` | account、帳戶名稱、轉出帳戶 | ✓ | 需與系統中的帳戶名稱**完全相同**；不會自動建立帳戶。轉帳時為轉出帳戶 |
| `分類` | category、類別、收支分類 | 收支必填 | 子分類以 `/` 分隔（也接受 `›`、`>`），例如 `餐飲/午餐`，最多兩層。找不到時可選擇自動建立（依類型建在收入或支出底下）。轉帳留空 |
| `轉入帳戶` | to_account | 轉帳必填 | 轉帳的轉入帳戶，不可與轉出相同 |
| `轉入金額` | to_amount | 跨幣別轉帳必填 | 轉入帳戶幣別的實際入帳金額；同幣別留空（等於轉出金額） |
| `對象` | payee、商家、店家、摘要、交易對象 | | 商家、付款人或收款人 |
| `備註` | note、memo、說明、附註 | | 任意文字 |
| `標籤` | tags、tag | | 多個以 `、`、`,`、`;` 分隔 |

金額一律以**帳戶的幣別**計算，不會換匯。

### 匯入規則

1. **先預覽**：上傳後系統逐列檢查，顯示每列狀態（可匯入 / 重複 / 錯誤）與原因；這時不會寫入任何資料
2. **錯誤列會略過**，其餘照常匯入；可修正後重新上傳錯誤的列
3. **重複判斷**：`日期 + 類型 + 帳戶 + 金額 + 轉入帳戶 + 對象` 都與**現有**收支相同即視為重複，預設略過（可關閉）。同一個檔案內的相同資料不視為重複（例如同一天買兩杯一樣的飲料）
4. 匯入在副本上執行，全部處理完才一次寫入，不會只匯入一半
5. 匯出的 CSV 重新匯入時，所有列都會是「重複」，不會產生重複資料

### 匯出

- 依日期由舊到新排列，欄位與匯入相同，可編輯後再匯入
- 分類輸出為 `上層/子分類`；金額為兩位小數的正數（方向看「類型」）
- 為避免 Excel 公式注入，以 `=`、`+`、`-`、`@` 開頭的文字欄位會加上前置單引號 `'`；匯入時會自動去掉

### 銀行對帳單轉換建議

多數銀行的 CSV 可直接匯入，只要：

1. 把欄名改成上表的名稱（或「也接受」的名稱），例如「交易日」→ 保留即可、「支出金額 / 存入金額」兩欄需合併成一欄「金額」（支出填負數）
2. 新增一欄「帳戶」，整欄填同一個帳戶名稱
3. 新增一欄「分類」，或先留空：留空時收入、支出列會顯示錯誤，可在 Excel 補上後再上傳

## 2. 完整備份 JSON

```json
{
  "format": "pft-backup",
  "version": 1,
  "exported_at": "2026-11-23T09:30:00.000Z",
  "base_currency": "TWD",
  "counts": { "accounts": 7, "categories": 29, "transactions": 1032 },
  "accounts": [
    {
      "id": "acc_0001", "name": "台新 薪轉戶", "type": "bank", "currency": "TWD",
      "opening_balance": "150000.00", "note": "", "is_archived": false,
      "created_at": "...", "updated_at": "..."
    }
  ],
  "categories": [
    { "id": "cat_0001", "name": "餐飲", "kind": "expense", "parent_id": null, "sort_order": 0, "created_at": "...", "updated_at": "..." }
  ],
  "transactions": [
    {
      "id": "tx_000001", "date": "2026-06-01", "type": "expense", "account_id": "acc_0001", "amount": "18000.00",
      "category_id": "cat_0012", "to_account_id": null, "to_amount": null,
      "payee": "房東", "note": "月租", "tags": [], "created_at": "...", "updated_at": "..."
    }
  ]
}
```

- 欄位與 API 相同（見 `CLAUDE.md` §5），金額為字串
- `version` 只在格式不相容時遞增；匯入時拒絕比程式新的版本
- 還原規則：
  1. 先驗證整份檔案（格式、id 不重複、所有參照都存在、每筆資料都通過與 API 相同的驗證），任何錯誤都不會動到現有資料
  2. 預覽顯示備份與目前資料的筆數，確認後才**取代**全部帳戶、分類與收支
  3. 保留原本的 id 與建立時間；之後新增的資料 id 接續最大編號
- 備份檔含完整財務資料，請妥善保存

## 3. API

| 方法 | 路徑 | 說明 |
|---|---|---|
| `GET` | `/export/transactions?<收支列表的篩選參數>` | 回傳 `text/csv`（UTF-8 + BOM）；不分頁 |
| `GET` | `/export/backup` | 回傳上方的 JSON |
| `POST` | `/import/transactions` | `{ content, dry_run = true, skip_duplicates = true, create_categories = true }` |
| `POST` | `/import/backup` | `{ backup, dry_run = true }` |

`POST /import/transactions` 回應（`dry_run=true` 時 `imported` 為「將匯入」筆數）：

```json
{
  "dry_run": true, "total": 5, "imported": 3, "duplicates": 0, "errors": 2,
  "created_categories": ["寵物", "寵物/飼料"],
  "warnings": ["忽略未知欄位「餘額」"],
  "rows": [
    { "row": 2, "status": "ok", "messages": [], "data": { "date": "2026-11-21", "type": "expense", "amount": "1234.00", "account": "現金錢包", "category": "餐飲/午餐", "to_account": "", "payee": "便當店" } },
    { "row": 5, "status": "error", "messages": ["找不到帳戶「不存在的帳戶」，請先在「帳戶」頁建立"], "data": { "...": "..." } }
  ]
}
```

- 檔案層級的錯誤（缺必要欄位、沒有資料列、超過上限、不是備份檔）回 `422 { detail }`
- 寫入端點需非唯讀身分（viewer 回 403）
